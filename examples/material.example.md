# 第1章 进程与调度

## 1.1 进程的基本概念

进程是程序在一次执行过程中的动态实例，它由程序段、数据段和进程控制块（PCB）三部分组成。
程序是静态的，可以长期保存在磁盘上；进程是动态的，有创建、就绪、运行、阻塞、终止五种基本状态。

| 项目 | 程序 | 进程 |
| --- | --- | --- |
| 存在形态 | 静态文件 | 动态执行实体 |
| 生命周期 | 长期保存 | 有生有灭 |
| 是否占资源 | 只占磁盘空间 | 占内存、CPU、IO |

PCB 里保存进程标识、状态、程序计数器、寄存器现场、优先级、资源清单等信息，是进程存在的唯一标志。

## 1.2 调度算法

常用的进程调度算法有四类：先来先服务（FCFS）、短作业优先（SJF）、优先级调度、时间片轮转（RR）。

时间片轮转的关键参数是时间片长度：

```
for each process:
    run for quantum q
    if not finished: enqueue again
```

时间片过大 → 退化为 FCFS；时间片过小 → 上下文切换开销占比过高。

# 第2章 同步与死锁

## 2.1 信号量

信号量 S 是一个整型量，只能通过 P（wait）和 V（signal）两个原语访问：

```c
void P(Semaphore *S) {
    S->value--;
    if (S->value < 0) block(S);
}

void V(Semaphore *S) {
    S->value++;
    if (S->value <= 0) wakeup(S);
}
```

S 的值含义：S>0 表示可用资源数；S=0 表示资源刚好用完且没有阻塞进程；S<0 时 |S| 等于阻塞队列中的进程数。

## 2.2 死锁

死锁发生的四个必要条件：互斥、请求并保持、不可剥夺、循环等待。破坏其中任意一个即可预防死锁。

银行家算法通过安全检查避免死锁：只要存在一个安全序列，就允许本次分配；否则让进程等待。

# 第3章 内存管理

## 3.1 分页与快表

页式存储把逻辑地址拆成页号和页内偏移，页表完成页号到物理块号的映射。

一次访存要查两次内存（页表 + 数据），有效访问时间约为 2t。快表（TLB）缓存最近使用的页表项，
命中时只需一次访存，有效访问时间接近 t。

## 3.2 页面置换算法

| 算法 | 特点 |
| --- | --- |
| OPT | 理论最优，无法实现，用作评价基准 |
| FIFO | 简单，可能出现 Belady 异常 |
| LRU | 性能接近 OPT，实现开销较大 |
| Clock | LRU 的近似，用访问位循环扫描 |
