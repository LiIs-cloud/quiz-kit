# 题库模板（把这个文件填完 → 转成题库）

> 用法：复制本文件，按下面的格式写题，然后
> `python kit/make_bank.py 我的题库.md -o 我的科目/quiz_bank.json`
> 支持 .md / .txt / .docx（Word 直接丢进来也行）。

规则很简单：

- 每题用 `## ` 开头，格式 `## 题号 | 第X章 | 题型`，题号随便写，章节和题型可省略；
- 选择题把选项写成 `A. xxx` 开头，答案写选项字母；
- 判断题写两个选项 `A. √ 正确` / `B. × 错误`，答案写 A 或 B；也可以只写「答案：正确」；
- 填空题的题干用 `____` 或 `【①】` 标空位，答案按空用「；」隔开；
- 简答/编程题把答案写在「答案：」下面，可以多行、可以贴代码；
- 「解析：」可选，会作为解析显示。

## 1 | 第1章 | 选择题
进程与程序最本质的区别是（ ）。
A. 程序是静态的，进程是动态的
B. 程序占内存，进程不占内存
C. 进程一定比程序大
D. 两者没有区别
答案：A
解析：程序是磁盘上的静态指令集合；进程是程序的一次执行，有生命周期和状态。

## 2 | 第1章 | 判断题
时间片轮转过长时，算法会退化成先来先服务。
A. √ 正确
B. × 错误
答案：A

## 3 | 第2章 | 填空题
信号量 S 的初值为 3，经过 5 次 P 操作和 2 次 V 操作后，S 的值是 ____，此时阻塞队列中有 ____ 个进程。
答案：0；0
解析：P 减 1、V 加 1；S=0 表示资源刚好用尽但没有进程阻塞。

## 4 | 第3章 | 简答题
简述页式存储管理中快表（TLB）的作用。
答案：页式存储每次访存都要先查页表，相当于访问两次内存。快表把最近用到的页表项放进高速缓存，命中时只需一次访存，把有效访问时间从 2t 降到接近 t。
命中率越高加速越明显；进程切换时要刷新或按 ASID 区分快表。

## 5 | 第3章 | 编程题
用 C 语言写出求 1+2+...+n 的递归函数。
答案：
```c
int sum(int n) {
    if (n <= 0) return 0;
    return n + sum(n - 1);
}
```
注意递归出口必须先判断。
